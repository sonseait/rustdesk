Managed Windows host setup (Windows x64 build 19041+)

Recommended: run rustdesk-managed-windows-x64-setup.exe, approve UAC and
accept the included Amyuni license in the installation wizard. No Python or
manual extraction is required on the target PC. Inno Setup directly runs the
native app/service installer and driver utility; it does not launch PowerShell.
The ZIP is a portable runtime bundle, not the service/driver setup entrypoint.
Driver attribution: Amyuni Technologies Inc., https://www.amyuni.com/
The included original license permits redistribution with acknowledgement and
states that advertising pages may be displayed. Driver files are unmodified.

Setup installs RustDesk in Program Files with an automatic service and installs
Amyuni's signed virtual display driver. It does NOT configure Windows auto-login,
disable the lock screen, change passwords, or weaken managed authorization.
Default virtual display mode is 2560x1440. Change the active resolution through
Windows Display Settings if another supported mode is preferred.
Existing displays can retain a Windows-saved mode. Select the virtual display
in Windows Display Settings and confirm its resolution. In the remote session,
select that display and a high image-quality preset. Higher resolution increases
bandwidth and encoder load; it does not guarantee lossless text rendering.

Keep RDP access while verifying:
- Service RustDesk is Running with Automatic startup.
- Managed enrollment/policy and credentials work for the installed service,
  not only the interactive portable application.
- Remote view/input works on the Windows lock/sign-in screen.
- Sign out and reboot; reconnect without opening an RDP session.
- Disconnect RDP; the virtual display remains capturable.
Do not claim unattended operation until these tests pass on the target machine.
If Windows requests a reboot for the driver, reboot using the RDP fallback.
Setup does not force reboot, sign out, or unlock the target machine.

Uninstall: use RustDesk's normal installed uninstaller for the app/service.
The setup wizard delegates installation to RustDesk and does not add a second
uninstaller. A setup failure can leave a partial installation; it does not
automatically roll back a service or driver that was already installed.
For the virtual driver, disconnect remote display sessions, open an Administrator
command prompt in the retained usbmmidd_v2 directory and use the vendor commands:
  deviceinstaller64.exe enableidd 0
  deviceinstaller64.exe stop usbmmidd
  deviceinstaller64.exe remove usbmmidd
Removing this driver affects other software using the same Amyuni device.
